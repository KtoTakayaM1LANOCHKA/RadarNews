# NewsRadar MVP · Senior за 3 дня

Прототип платформы поиска и проверки локальных событий для News Media Holding. **Это запускаемое локальное демо, не готовый сервис для реальных редакций.** Все события, создаваемые при первом запуске, вымышленные. Автоматическая проверка фактов не доказана и **не** заменяет человека.

## Запуск

**Windows:** распакуйте архив и запустите `start_windows.bat` (нужен установленный Python 3.11+).

**Linux / macOS:**

```bash
cd RadarNews
chmod +x start_linux.sh
./start_linux.sh
```

Или вручную:

```bash
python -m venv .venv
# Linux: source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- Пользовательское приложение: **http://127.0.0.1:8000/**
- Редактор: **http://127.0.0.1:8000/editor**
- Swagger API: **http://127.0.0.1:8000/api/docs**
- Состояние: **http://127.0.0.1:8000/health**

**macOS:** двойной клик по `start_mac.command`.

**Вход.** Приложение сразу открывает экран входа по телефону и запоминает пользователя на устройстве (сессия 30 дней). В демо-режиме код показывается на экране, SMS не отправляется. Пароль редактора для локального демо: `change-this-before-deployment`. Номер из `ADMIN_PHONE` (по умолчанию `+79999999999`) входит как администратор. **Панель доступа находится в личном кабинете над репутацией**: переход в редакцию, привязка Telegram, а у администратора — назначение и снятие роли редактора. Пользователь может ввести демо-пароль редакции прямо в кабинете. Роль хранится в аккаунте; отзыв доступа действует на существующие сессии и рассылку сразу.

### Демонстрация полного цикла

1. Войдите по тестовому номеру, например `+79990000000`. Карта спросит местоположение и покажет события рядом; фильтры — по типу и тематике.
2. **«＋ Прислать новость»**: опишите событие, при желании приложите фото/видео. Новость попадёт в закрытую редакторскую очередь.
3. Откройте `/editor`, раздел **«Новости»**, нажмите на новость — она откроется на весь экран (выход стрелкой ←).
4. Оцените значимость и эксклюзивность, затем **«Опубликовать»**, **«Отклонить»** или **«Создать задачу»** для проверки пользователями. Публикация окончательна; отклонённую новость можно опубликовать позже.
5. Задача появляется в приложении во вкладке **«Лента»**: пользователи рядом жмут **«Подтвердить»** или **«Опровергнуть»**.
6. В разделе **«Подтверждение»** редактор принимает или отклоняет ответы. Принятый ответ закрывает задачу и возвращает новость редактору.
7. Баллы и деньги приходят автору на следующий день и видны в **личном кабинете** (аватар в шапке).

## Баллы, репутация и вознаграждения

Все значения — демо-тарифы, заданы константами в начале `app/main.py`. Реальные выплаты не подключены.

| За что | Баллы репутации | Деньги |
|---|---|---|
| Достоверная новость · «Обычная» (10–59 баллов) | 10 + 0,45 × значимость + 0,45 × эксклюзивность | 150 ₽ |
| Достоверная новость · «Значимая» (60–79 баллов) | по той же формуле | 500 ₽ |
| Достоверная новость · «Эксклюзив» (80–100 баллов) | по той же формуле | 1500 ₽ |
| Принятое подтверждение или опровержение по задаче | +10 | — |
| Отклонённое подтверждение или опровержение | −5 | — |
| Недостоверная (отклонённая) новость | −20 | — |

- Значимость и эксклюзивность (0–100) выставляет редактор при решении; чем они выше, тем больше баллов и выше тип новости.
- Начисления и списания приходят **на следующий день** (00:00 по Москве) после решения редактора; до этого они показаны в кабинете как «придёт завтра».
- Репутация начинается с нуля (стрелка шкалы по центру): плюс двигает её вправо, минус — влево; край шкалы — ±300 баллов.
- Деньги копятся в кошельке; кнопка **«Вывести»** доступна от 100 ₽ и создаёт заявку (таблица `withdrawals`).

## Развёртывание в Amvera Cloud

В корне лежит готовый `amvera.yml` (Python 3.12, pip, порт 8000, постоянное хранилище `/data`). В Amvera приложение само хранит базу и загрузки в `/data` (определяется по переменной `AMVERA`).

1. Создайте в Amvera приложение и загрузите файлы проекта через интерфейс или `git push` в репозиторий Amvera. Не загружайте `.venv/`, `.env`, `*.db`, `uploads/` — они уже в `.gitignore`.
2. В разделе **«Переменные»** задайте (пароль — как секрет) и перезапустите контейнер:

| Переменная | Значение |
|---|---|
| `DEMO_MODE` | `1` — иначе вход редактора по паролю отключён |
| `DEMO_OTP` | `1` — код входа показывается на экране (SMS-провайдер не подключён) |
| `EDITOR_PASSWORD` | свой надёжный пароль редактора |
| `ADMIN_PHONE` | номер администратора; **не оставляйте `+79999999999`** |
| `TELEGRAM_BOT_TOKEN` | токен бота, **секрет**, не добавляйте в Git |
| `NEWSRADAR_PUBLIC_URL` | `https://radar-trigger.msk1.amvera.tech` — HTTPS-корень приложения для Mini App |
| `NEWS_WORKER_ENABLED` | `1` — автопоиск, Telegram и рассылка запускаются вместе с веб-сервером |

3. Откройте выданный домен: `/` — приложение, `/editor` — редакция, `/health` — проверка.

**Важно.** Пока `DEMO_OTP=1`, код входа виден любому, кто ввёл номер, поэтому под любым номером, включая номер администратора, может войти кто угодно. Для публичной работы нужен SMS-провайдер; до этого держите `ADMIN_PHONE` в секрете и не храните в сервисе реальные данные.

### Реально работает

- SQLite и FastAPI, Swagger, реальное сохранение событий и ответов;
- создание/отклонение/публикация новостных карточек (публикация только внутри MVP);
- задачи на подтверждение, геофильтр (гаверсинус), раздельная карта и лента, 3 основных вкладки;
- регистрация с **симулированным** OTP, сессии, роли редактора и пользователя;
- загрузка медиа и ограничение доступа к оригиналам;
- EXIF-индикаторы (наличие даты/GPS), а не доказательство подлинности;
- цикл «проверка → редактор → доработка → ответ пользователя → редактор»;
- репутация, баллы и кошелёк с отложенным на день начислением; смена ника и аватара;
- настраиваемый рекламный маркер, увеличенный размер маркеров для популярных событий;
- Telegram long polling, Mini App с проверкой подписи Telegram, приём текста/фото/видео и персональные уведомления редакторам; текстовые вебхуки MAX, VK и WhatsApp (после настройки платформ);
- поиск новостей в интернете через Google News RSS без ключа (либо Brave Search с ключом), ручной импорт, автоматический сбор по запросам/RSS/Atom из базы;
- опциональная LLM-сортировка по значимости и списку вопросов, если задан OpenAI API key.

### Пока демонстрация / ограничения

- **AI-фактчекинг:** без внешнего ключа работает прозрачный набор правил (анализ числа ответов и явных противоречий). **Никакой neural truth score не выдаётся.** При подключённом LLM API модель оценивает лишь тему/потенциальную важность, не доказанность факта.
- **Поиск:** используется публичная новостная выдача Google News RSS; для общего веб-поиска можно подключить Brave Search API. Сбор не охватывает весь интернет и не устанавливает достоверность. Закрытые чаты и приватные данные не индексируются. Найденные материалы поступают только в закрытую редакторскую очередь. Новости без проверенных координат не отображаются на карте; редактор может указать координаты при решении.
- **Карта:** при доступном интернете используется Leaflet/OpenStreetMap (плитки по сети); если сеть недоступна — схематичная карта без реальных названий улиц.
- **Настоящая SMS:** не подключена. Нужен SMS-провайдер, защита от ботов и юридические основания обработки телефонов.
- **Видео/фото из ботов:** Telegram адаптер умеет скачивать и передавать медиа до 12 МБ. MAX/VK/WhatsApp вебхуки этого MVP принимают только текст. Медиаадаптеры для них требуют работы с соответствующими API.
- **Монетизация:** рекламные карточки и баллы демонстрационные, платежей нет.
- **Редакторская CMS:** изменения статуса локальны, нет внешней публикации. Интеграция с News Media Holding требует согласованного доступа.
- **Продакшен:** перед публичным релизом необходимы полноценная аутентификация редакторов, SMS-провайдер, отдельное хранилище медиа, антивирус, очередь задач, мониторинг, антиспам, политика хранения/удаления данных, журнал аудита и согласия, резервирование и ревью безопасности.

## Карта: OpenStreetMap

В пользовательском приложении `/` карта строится библиотекой **Leaflet 1.9.4** на тайлах **OpenStreetMap** (`tile.openstreetmap.org`). Ключ API не нужен.

- Leaflet подгружается с `unpkg.com` с проверкой целостности (SRI), тайлы — с серверов OpenStreetMap. Нужен доступ в интернет.
- События показаны круглыми маркерами, размер отражает популярность, рекламные выделены и отключаются. По клику открывается карточка с действиями «Подтвердить/Опровергнуть» для открытых задач на подтверждение.
- Если библиотека или сеть недоступны, показывается сообщение о причине и резервная схематичная карта.
- Публичные тайлы OpenStreetMap подходят для демо и небольшой нагрузки ([правила использования](https://operations.osmfoundation.org/policies/tiles/)). Для продакшена нужен собственный или коммерческий тайл-сервер.
- Переменная `YANDEX_MAPS_API_KEY` в `.env` больше не используется.

## Боты и развёртывание

В `.env.example` перечислены переменные. `.env` автоматически загружается через `python-dotenv`; переменные окружения имеют приоритет. Токены хранятся в `.env` или серверных секретах, не в репозитории.

### Telegram: бот и Mini App

1. Задайте на сервере `TELEGRAM_BOT_TOKEN` как секрет и `NEWSRADAR_PUBLIC_URL=https://radar-trigger.msk1.amvera.tech`. Адрес должен открывать этот же сервер по HTTPS.
2. Запустите обычный `uvicorn app.main:app --host 0.0.0.0 --port 8000`. Бот, сборщик и рассылка стартуют автоматически (`NEWS_WORKER_ENABLED=1` по умолчанию). При старте бот получает свой username и настраивает меню приложения и команды.
3. В Telegram отправьте `/start` или `/app`. Кнопка **«Открыть NewsRadar»** и меню открывают существующее приложение: карта, задачи, отправка новостей и медиа, профиль, репутация, кошелёк. Вход происходит по проверенному сервером `initData` Telegram, без повторного ввода телефона. Подпись и срок действия проверяются; `initDataUnsafe` для авторизации не используется.
4. Чтобы работать редактором в Telegram, сначала войдите на сайте в свой редакторский аккаунт. В **личном кабинете → Панель доступа → Подключить уведомления** получите одноразовую команду `/start <код>` (10 минут) и отправьте боту **в личный чат**. После привязки Mini App открывает тот же аккаунт с его ролью.
5. Новые новости из поиска, RSS, сайта и бота, а также ответы на задачи приходят подписанным редакторам. Кнопка уведомления открывает нужную новость в редакции через Mini App. Демонстрационные события и старые материалы при подключении не рассылаются.

Команды: `/app`, `/help`, `/nearby` (задачи без геоперсонализации), `/search запрос` (поиск для привязанных редакторов), `/stop` и `/subscribe`. Обычный текст/фото/видео передаются в очередь; повторная обработка того же Telegram-сообщения не создаёт новую новость. История и вознаграждения за сообщения боту видны в Mini App. При ошибке медиа текст сохраняется и бот сообщает о проблеме.

Привязку можно удалить в кабинете. Роль проверяется перед каждой отправкой; снятие роли редактора отменяет ожидающие уведомления. Ошибки сети и 429 повторяются с задержкой, блокировка бота (403) отключает подписку. Очередь доставки и смещение `getUpdates` сохраняются в SQLite. Доставка — как минимум один раз: если Telegram принял сообщение, но ответ потерялся, возможен повтор после сбоя.

Для отдельного процесса установите `NEWS_WORKER_ENABLED=0` **только у веб-процесса** и запустите `python -m app.bots.telegram_bot` с той же базой и переменными. Встроенному Telegram не нужен `INGEST_SECRET`: он использует внутренний приём данных. Этот секрет по-прежнему нужен внешним HTTP-адаптерам. Блокировки в SQLite исключают одновременный опрос Telegram несколькими процессами с одной базой. Не запускайте другой сервис с тем же ботом; активный Telegram webhook несовместим с long polling и должен быть отключён владельцем бота перед запуском.

### Поиск в интернете и база источников

В **Редакция → Источники** доступны:

- поиск новостей и добавление результата в очередь;
- добавление/редактирование поисковых запросов и RSS/Atom-лент, пауза/возобновление;
- интервал проверки 5–1440 минут, тематика, время последней проверки, число импортов и ошибки;
- кнопка **«Проверить сейчас»**.

По умолчанию создаётся редактируемый запрос **«новости России сегодня»**, проверка каждые 15 минут. Список хранится в `news_sources`, связи с импортированными событиями — в `source_items`. Каждый проход берёт до 20 последних результатов на источник, дубли по ссылке между источниками пропускаются. Поддерживаются ETag/Last-Modified, ограничение ленты 2 МБ, проверка публичности адреса и перенаправлений. После ошибки источник повторяется через 5 минут. RSS/Atom не требуют дополнительных API-ключей. Источники должны возвращать RSS/Atom, обычная HTML-страница не является лентой.

Миграции создают новые таблицы и поле роли автоматически, существующие новости/пользователи/балансы сохраняются. Перед обновлением сохраните резервную копию постоянного хранилища `/data` при остановленном приложении. Новые переменные Amvera задаются в её настройках: `.env` из локального окружения не переносится через Git. После обновления кода перезапустите приложение и проверьте `/health`, `/app` в Telegram и привязку редактора.

### MAX (текстовые вебхуки)

- Создание бота требует верифицированного профиля подходящего типа на площадке MAX.
- В `MAX_WEBHOOK_SECRET` установите выбранный секрет, а в `INGEST_SECRET` — внутренний секрет подключения.
- Подписка MAX должна указывать **HTTPS:443** маршрут `/hooks/max` и тот же секрет. Поддерживается событие `message_created`.
- Внешние обращения должны проходить через проверенную TLS-инфраструктуру; не выставляйте демо-OTP и демо-пароль публично.

Официальная документация: https://dev.max.ru/docs-api/methods/POST/subscriptions

### VK (текстовые вебхуки)

- Включите Callback API сообщества.
- Настройте `VK_WEBHOOK_SECRET`, `VK_CONFIRMATION_CODE`, `INGEST_SECRET`.
- URL вебхука: `/hooks/vk`; обрабатываются `confirmation` и `message_new`.
- Текущий адаптер принимает **только текст**; остальные типы вложений ещё не реализованы.

### WhatsApp Business (текстовые вебхуки)

- Нужен аккаунт WhatsApp Business Platform/Cloud API с разрешённым доступом.
- Настройте `WHATSAPP_VERIFY_TOKEN`, `WHATSAPP_APP_SECRET`, `INGEST_SECRET`.
- URL: `/hooks/whatsapp`; GET отвечает на проверочный вызов, POST проверяет заголовок HMAC SHA256.
- Текущий адаптер принимает **только текст**; запросы медиа/ответов пользователю не реализованы.

**Невозможно автоматически активировать и развернуть ботов «во всех соцсетях» без токенов, регистрации приложений, модерации и HTTPS-публичного сервера.** Архитектура предусматривает единый нормализованный приём информации. Новые адаптеры добавляются по образцу `/hooks/...` и `/api/integrations/ingest`.

## Подключение поиска и AI

```bash
# Ключи необязательны. Не вставляйте настоящие секреты в код или Git.
export BRAVE_SEARCH_API_KEY='...'
export OPENAI_API_KEY='...'
export OPENAI_MODEL='gpt-4o-mini'
```

- `/api/discovery/search` — искать новости по запросу (редакторская сессия обязательна; без ключа — Google News RSS).
- `/api/discovery/import` — вручную импортировать ссылку, заголовок и описание как непроверенное событие.
- `/api/events/{id}/analyze` — правила + опциональная LLM-сортировка с дополнительными вопросами для редактора.

LLM не имеет права утверждать, что новость достоверна, без независимых доказательств. Решения о публикации принимают люди.

## Данные и безопасность

- Геолокацию запрашивает браузер при открытии карты и по кнопке «⌖ Где я»; координаты отправляются только с новостью и только по галочке пользователя.
- Отправлять доказательства можно без геолокации; не требуйте присутствия у опасных происшествий.
- Точные исходные файлы и координаты не должны становиться публичными автоматически.
- Метаданные EXIF могут быть удалены или подделаны; их наличие **не** доказывает место или время съёмки.
- Публичная карта содержит только редакционно одобренные статусы `published`/`order`; новые неподтверждённые пользовательские новости скрыты в редакторской очереди.
- Рекламные маркеры подписываются, не получают преимуществ по достоверности и могут скрываться пользователем.
- Для аудитории младше 18 лет особенно важно не поощрять самостоятельные выезды к происшествиям, раскрытие личных данных или публикацию опасного контента.

**Проект предоставлен для прототипирования и демонстрации.**

## Интерфейс

- Общий стиль приложения и редакции — светло-голубая палитра с тёплым акцентом; темы «как в системе» (по умолчанию), светлая и тёмная переключаются в шапке.
- Приложение: нижняя панель «Карта · ＋ Прислать новость · Лента», личный кабинет по аватару, анимированный радар на экране входа и в «Прислать новость».
- Редакция: кнопка ☰ скрывает и показывает боковое меню; разделы «Обзор», «Новости», «Задачи для проверки пользователей», «Подтверждение», «Источники», «Карта», «Аналитика», «Пользователи».
- Файлы: `app/static/ui.css` и `ui.js` (общие), `index.html` + `app.js` (приложение), `editor.html` + `editor.js` (редакция). `styles.css` оставлен для совместимости с прежним оформлением.
